# HabitTracker

Aplicación de escritorio desarrollada en C# .NET 8 con Windows Forms para la gestión y seguimiento de hábitos diarios, incluyendo control de rachas y visualización de progreso.

---

## Tecnologías

- C# .NET 8
- Windows Forms
- Entity Framework Core
- SQL Server
  
---

## Funcionalidades
- Crear hábitos diarios
- Dar seguimiento al progreso
- Visualizar rachas
- Gestionar historial de hábitos
